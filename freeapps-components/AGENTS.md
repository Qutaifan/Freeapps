# freeapps-components

## ⛔ Stop — this directory is not the website

A Vite + React + TypeScript scaffold that is **never deployed and not linked from any
live page**. Changes made here have **zero effect on qutaifan.com**.

The live site is hand-maintained static HTML at the repository root (`index.html`, the
`best-*` / `free-alternative-to-*` pillars, `reviews/`, `vs/`, `how-to/`). That is where
UI work belongs. Earlier versions of the root `AGENTS.md` pointed agents here for UI
changes; that instruction was wrong and has been removed.

**Do not work in this directory unless you have been explicitly asked to revive or remove
it.** If you were about to change a component here to fix something a user sees on the
site, you are in the wrong directory.

## Purpose

Dead weight, retained rather than deleted. It contains a React re-implementation of the
site's UI — a hero, tool cards, a search modal, ad slots — that was never wired up. The
only thing keeping its toolchain alive is `.github/workflows/hermes_curator.yml`, which
runs `npm ci && npm run lint && npm run build` here on its nightly schedule.

## For AI Agents

### Working In This Directory

If you have been explicitly asked to work here:

- `src/data/tools.ts` is a **second copy of the tool catalogue**, separate from the
  generated `../tools.json`. It is not kept in sync by `sync_tools_from_obsidian.js`.
  Treat it as stale, and never maintain the same tool in two places.
- `src/components/AdSenseBanner.tsx`, `InFeedAdCard.tsx`, and `StickyAnchorAd.tsx` render
  ad markup that is not served. **Do not copy slot IDs or placement logic out of here
  into live pages** — the live rules are in the root `AGENTS.md` §5, and a sticky anchor
  unit is not among the three units this site actually uses.
- `dist/` is committed and therefore deployed. Anything you build lands at
  `/freeapps-components/dist/…` as a public URL. `robots.txt` disallows
  `/freeapps-components/`, but it is still served.
- **Removing this directory is not a self-contained change.** `hermes_curator.yml` builds
  it nightly; that workflow must be updated in the same commit or the job starts failing.

### Testing Requirements

```bash
cd freeapps-components
npm ci
npm run lint     # must pass — the nightly workflow runs it
npm run build
```

None of this verifies anything about the live site.

### Common Patterns

Function components with a props interface declared above the component, one component
per file, plain CSS in `App.css` / `index.css`.
