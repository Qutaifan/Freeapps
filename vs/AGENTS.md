# vs

## Purpose

Head-to-head comparison pages. Each comparison is a directory holding one `index.html`,
which makes its 200 URL the **trailing-slash** form — the opposite of the review pages.

## Subdirectories

| Directory | Purpose |
|-----------|---------|

| `claude-vs-chatgpt/` | AI-assistant comparison. Serves 200 at `/vs/claude-vs-chatgpt/`. |

## For AI Agents

### Working In This Directory

- **URL form is inverted versus `reviews/`.** `x/index.html` returns 200 at `/vs/x/`
  *with* the trailing slash and 308-redirects `/vs/x`. Canonicals, `og:url`, sitemap
  entries, and internal links must use the trailing-slash form. Both directions have been
  wrong in this repo — verify with `curl -I` against production.
- Naming is `<a>-vs-<b>/`, alphabetical where there is no clear primary. Keep it.
- A comparison page must not contradict either tool's review page. Contradiction across
  pages is one of the checks `content_quality.py` runs, and one of the reasons it fails.
- Both tools compared should exist in `tools.json`. If a tool has a review page, link to
  its extensionless `/reviews/<slug>` URL.
- These are pillar-class pages for ad purposes: up to two units
  (`qutaifan-pillar-top`, `qutaifan-pillar-mid`), ≥400 words apart, `min-height: 250px`
  reserved on each.
- **Never fabricate a verdict, rating, or testing claim.** Comparison framing invites
  invented benchmark numbers — do not write any.
